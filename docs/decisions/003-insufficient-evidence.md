# 课程资料无法支持问题时的行为

日期：2026-11-25。状态：用户已确认产品行为，自动判断及回答实现待完成。

## 决策

在“课程资料只有数据库知识，学生问明天上海会下雨吗”的例子中，用户选择：提示课程资料不足，并建议换个问题或补充资料。首版不在这类问题上继续给出通用知识回答。

人工示例提示为：“当前课程资料不足以回答这个问题。你可以提出课程相关问题，或补充能够支持该问题的资料。”这是对选择的文字示意，不是实际模型回答，也不要求逐字匹配。

不能引用不相关的课程片段支持结论，也不能因为没有依据而扩大到其他同学的私人笔记。已有登录和课程权限检查继续生效；无课程资格属于访问控制失败，不应被包装成普通的资料不足。

## 为什么需要单独判定

第一条真实检索实验中，正常情况返回 B/A；删除 B 后固定 Top-K=2 仍返回 A/C，C 是索引知识，与转账问题不相关。因此“有结果”或“结果有两条”不能证明回答有依据。

天气问题对应[第二条验收用例](../../evals/cases/insufficient-evidence-v0.1.json)。目前只记录人工预期，尚未调用模型或实现资料充分性判断。距离阈值、是否使用额外判断模型及交互方式仍需用更多问题验证，不能用第一道题的距离拟合一个全局规则。

本决策没有改变此前“已有 A 但缺少具体转账资料时先补查，仍只有 A 则依据 A 回答”的选择。部分证据可以支持有边界的回答，与完全没有支持依据的例子分开评测。
