# 资料管理阶段验证记录

日期：2026-11-24。本阶段完成教师公共资料和学生私人笔记管理，尚未实现向量化 worker、真实 Embedding 与模型回答。11 张业务表 DDL 没有变化。

## 已实现

- 资料上传、按课程/种类/标题筛选、24 条分页、本人资料页、鉴权下载、纯文本预览、改名、版本替换及逻辑删除。PDF 当前仅下载查看。
- 资料类型由服务端角色决定，客户端不能指定所有者；其他学生和教师不能访问学生私人笔记。退课后本人笔记仍可下载、改名、删除，但不可替换。
- 扩展名及真实内容校验、UTF-8 校验、文本型 PDF 提取检查、默认 10 MiB 限制；拒绝空正文、扫描件、加密 PDF 及伪造格式。
- 幂等键持久化，同键不同内容冲突；替换递增正文版本。资料与索引任务同事务写入，替换及删除作废旧任务与分块。
- 事务失败安全补偿文件；COMMIT 确认丢失时不删除已经提交的文件，无法确认数据库状态时保留文件供后续核对。
