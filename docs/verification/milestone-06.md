# 单份资料向量发布

日期：2026-11-25。当前已支持从已有资料任务读取 PARSED 分块、调用百炼并原子发布到正式 SeekDB 业务表；尚未开放检索 HTTP 或课程问答。

## 实现与约束

- 任务增加 stage=PARSE/EMBEDDING 和 JSON model_calls，维持一份资料一个正文版本一条任务。两个 worker 按阶段领取，首次进入向量阶段重新计数，失败重试保留已解析分块和历史审计。
- 默认命令不联网，只有显式 --live --document-id N 才处理指定资料。初始每份最多 32 段、每批最多 8 段、每段最多 600 字符；全部分块在请求前检查，超范围不发请求、不截断。上限为工程默认值，不是经用户评测得出的最佳参数、模型 Token 限制或累计费用硬限额。
- 云端调用不持有数据库行锁。每批调用前续租、确认资格并写入 IN_FLIGHT；返回后保存实际用量、请求 ID、耗时和配置，未知用量不补零。记录不含片段正文或密钥。
- 有效租约、token、阶段、资料版本及状态共同守护写回。发布前比较完整分块 ID/顺序/正文摘要，并复核上传者资格；所有向量、当前标记、READY/SUCCEEDED 在同一事务更新。向量 SQL 写入后再次检查租约，防止慢 SQL 占用锁期间过期仍发布。异常会整体回滚，部分向量不能被检索。
- 删除/替换作废旧当前标记及未完成任务；退课后的检索由 SQL 当前关系过滤。旧 worker 的结果不能复活已删除、替换或由新 worker 发布的资料。迟到调用仅允许补自己的审计项，保留实际费用线索。
- 已处理的模型错误进入 FAILED，不自动产生下一次模型请求。页面重试只排队，仍需维护者再次显式执行。进程中断后再次运行可按过期租约接管，受每轮最大次数约束；原 IN_FLIGHT 调用可能已经计费，接管不提供外部“恰好一次”保证。
- 同时更新资料 API 的 index_stage、错误提示及页面的解析/向量化/可检索文字。未新增页面入口或操作按钮，不改变现有布局。

## 数据库迁移

sql/006_embedding_jobs.sql 由 app.migrate 条件执行，扩展阶段与调用审计；原有 PARSED 任务迁至 EMBEDDING。--vectors 按当前配置添加 document_chunks.embedding VECTOR(1024)，已有列维度不符时拒绝，不改写列或清空数据。新环境 bootstrap 包含上述迁移。

本机 `python -m app.migrate --vectors` 连续两次执行通过，已有行保留；更新后的 bootstrap 在已有库上再次执行通过。未配置 ANN 索引，继续使用精确排序。
