# 登录后的资料检索与原文预览

日期：2026-11-25。当前可以从课程工作台输入问题并查看实际授权片段，没有调用 DeepSeek 或生成答案。

## 实现

- POST /api/v1/courses/{course_id}/search：问题 1–600 字符，客户端 request_key；身份来自 HttpOnly 登录 Cookie，不接受前端指定所有者。
- GET /api/v1/searches/{request_id}：仅本人可读取，且仍需具备课程资格。每次读取结果重新验证全部片段的版本、READY、未删除、当前标记及 profile。
- 新增 retrieval_requests 为第 12 张表，持久化请求、截止时间、调用审计及片段引用。问题保留在本地数据库，不写入日志；结果不复制私人原文，只保存引用、版本和距离。
- 同键同问题复用结果，异内容返回 409，并发同键只允许一个请求发起模型调用。每位用户初始每分钟 6 个新请求；检查权限、向量列和可检索资料后才发送查询，没有候选不调用模型。
- 60 秒截止时间为工程默认值。处理中请求再次读取时判定过期，已处理的错误不自动重试。返回用量未知时保留 null；保存结果前，包括 SQL 排序完成后，均检查截止时间，迟到结果不发布。
- 新 React 组件以“资料检索”标明当前能力，最多返回两个相近片段，可切换查看原文与下载原资料。正文为纯文本。明确提示“检索片段不等于回答依据充分，尚未生成答案”，不将距离展示为正确率。

## 自动验证

专项测试覆盖登录、幂等、跨用户读取、无候选时不调用、缓存结果在删除/替换/退课后拒绝、模型失败不重试、频率限制、调用前后权限、截止时间、并发同键及输入/来源校验。另补充排序 SQL 期间超时不发布结果的测试。

TypeScript + Vite 生产构建通过。最终完整后端回归 126 passed，90.28 秒，含 12 项新增检索接口测试，有 1 条既有 Starlette/httpx TestClient 弃用提示。本轮模型自动测试使用替身，不代表真实模型效果。

## 真实浏览器验证

建立并保留明确标注的自编演示课程“检索演示：事务与转账”，A 为教师公共资料，B 为 student1 的私人笔记；student2 同样选课，便于后续体验身份差异。两份资料均通过真实上传服务、解析及百炼向量发布。

浏览器使用 student1 登录，输入事先使用的转账问题，真实 HTTP 检索返回 B/A。选择 A 后原文区域切换为事务原子性说明。再点击“查看结果”复用原请求，数据库中该课程只有一条检索请求、一次查询模型调用。详细摘要见 [search-ui-live.json](search-ui-live.json)。

## 边界

返回结果只代表语义相近，不证明所有片段与问题相关，也不能称为完整 RAG 答案。自动补查、依据充分性判断、DeepSeek 回答、引用检查与问答历史仍待实现。检索限流和输入约束不是累计费用硬限额。预览服务为本地开发用途，检查结束后停止；按 README 启动即可体验保留的演示资料。
